# Architecture decision records

Create numbered records such as `0001-organizer-authentication.md` when a feature changes authentication, authorization, persistence, privacy, payments, reminder scheduling, or deployment topology.

Each ADR records:

- Status and date
- Context
- Decision
- Alternatives considered
- Consequences
- Related feature requirements and artifacts

Accepted ADRs are historical records. Supersede them with a new ADR instead of rewriting the original decision.
